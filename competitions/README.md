# Official CTF competitions

Use this directory only for a CTF competition that was **actually attended**. This package does not claim that any specific event has been attended. Start from [`TEMPLATE-KOMPETISI-CTF.md`](../templates/TEMPLATE-KOMPETISI-CTF.md).

For each event, record the official URL, organizer, date/timezone, individual/team format, public participant/team name, and official scoreboard/result evidence when available. Scores and placements are optional and must be verifiable. CTFtime can help discover events; a team rating is not an individual certificate.

This is an event-level record, not a full solution write-up. Independent practice write-ups belong only in [`ctf-writeups/practice/`](https://github.com/madanisora/ctf-writeups/tree/main/practice). If a competition result motivates a separate, reproducible research experiment, link the experiment in [`reverse-engineering-lab`](https://github.com/madanisora/reverse-engineering-lab) (link to a specific experiment only after it exists). Do not publish challenge solutions or flags if the event rules prohibit publication.
